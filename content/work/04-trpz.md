TRPZ was a client build at White Sunrise — a trip-booking web and mobile application with end-to-end payment processing. I built it from clickable prototype to production, owning Laravel on the backend, Vue on the frontend, and the full release lifecycle.

## Payments and accounts

The payment flow integrated the Authorize.net SDK for real-money transactions — credit card tokenization, recurring-billing support for travel packages, and refund handling from admin accounts. Role-based permissions separated the customer booking experience from the admin back-office cleanly.

## Tech and rhythm

Laravel 5.x + Eloquent on the backend, Vue.js + Vue Router on the frontend, MySQL for persistence. Vagrant for local dev parity. I moved fast, shipped weekly, and kept the scope tight — the feature set matched the problem shape, nothing more.
